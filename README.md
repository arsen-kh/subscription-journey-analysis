# От пробного доступа до первой оплаты

Учебный проект Арсена по бизнес-анализу B2C-сервиса по подписке с управлением через Telegram-бот.

Фокус проекта — путь нового пользователя от пробного доступа к подключению и первой оплате.

История импортируется по этапам. Авторские даты приблизительно восстановлены по периоду работы, указанному автором.
