# Предложение первой доработки

Сервис по подписке с управлением через Telegram-бот. Версия для обсуждения от 7 ноября 2026.

## Задача

Помочь новому пользователю перейти от выданного пробного доступа к первому подключению. Первая версия объединяет понятный выбор клиента с возвратом к инструкции из списка устройств. Рассылку помощи проверить отдельным этапом.

## Страница настройки

После автоматического определения платформы первым показывается короткий блок настройки. Карточка состояния подписки доступна ниже. Пользователь видит название выбранного владельцем основного приложения и следующие действия.

1. «Установить приложение». Рядом доступен переход «Уже установлено» ко второму шагу.
2. «Добавить подписку». При нажатии открывается соответствующий клиент с импортом. Если это не сработало, открывается инструкция ручного добавления.
3. «Включить подключение». Короткая инструкция с названиями кнопок для конкретного клиента.

Ниже находятся «Другие приложения» и «Не получилось подключиться». Первый пункт раскрывает действующие альтернативы, второй предлагает выбрать шаг затруднения и перейти к соответствующей инструкции. Системные разрешения описываются в контексте конкретной платформы.

Клиент по умолчанию утверждается владельцем после проверки чистой установки. По данным кандидаты для iOS — Happ и RabbitHole, для Android — Happ. На Windows выбор требует отдельной проверки. Новые инструкции существующих клиентов остаются доступны через «Другие приложения». Популярность зависит в том числе от текущих рекомендаций.

## Бот

В разделе устройств при нуле зарегистрированных устройств показывается текст «Пока нет добавленных устройств. Начните с настройки приложения» и кнопка «Подключить первое устройство». Она открывает актуальную страницу текущей подписки. Перед переходом проверяется доступность подписки.

Для истёкшего доступа бот показывает возможность покупки и её условия. Перевыпуск остаётся дополнительным действием с объяснением последствий, согласованным с владельцем.

## Примеры приёмки

| Исходное состояние | Действие | Ожидаемый результат |
|---|---|---|
| Новый пользователь, активный пробный доступ, ноль устройств | Открывает устройства | Видит кнопку первой настройки и попадает в инструкцию своей подписки |
| Приложение уже установлено | Выбирает «Уже установлено» | Переходит к добавлению подписки без повторной установки |
| Автоимпорт не открыл клиент | Выбирает помощь по добавлению | Получает рабочий ручной путь для выбранного клиента |
| Нужен другой клиент | Раскрывает альтернативы | Видит существующие варианты и соответствующие им инструкции |
| Автоматически выбрана неверная платформа | Меняет платформу | Получает подходящие приложения и инструкции, персональная подписка сохраняется |
| Срок истёк до нажатия кнопки в старом сообщении | Пытается открыть настройку | Получает актуальное состояние доступа и понятный следующий шаг |

## Проверка результата

Перед запуском пройти сценарии чистой установки и уже установленного приложения на поддерживаемых устройствах. Сохранить версию инструкции, платформу и выбранный клиент в журнале событий. Первую активацию сверять по панели после подтверждения часового пояса.

Измерять долю пользователей с первым подключением за 24 часа, обращения по настройке и ошибки импорта. Бизнес-метрика — первая успешная оплата за семь суток от выдачи. Нужны полные окна наблюдения. Тестовые аккаунты исключаются. Владелец согласует целевую прибавку, объём пилота и способ сравнения до реализации.

## Сообщение товарищу

Посмотрели путь в боте и данные по приложениям. Happ и RabbitHole дают около 89% записей устройств. Предлагаю для начала упростить страницу настройки — один основной клиент на платформу, остальные под «Другие приложения», плюс добавить «Подключить первое устройство» в пустой список устройств. Это небольшая первая версия, которую можно проверить отдельно от рассылок. Нужно вместе выбрать основной клиент по каждой платформе и пройти чистую установку. Затем посмотрим подключения за сутки и обращения по настройке. Ещё заметили, что условие купленной подписки для реферальных дней стоит уточнить в справке.
