# Источник и определения

Использован снимок двух баз подписочного сервиса от 7 ноября 2026 года. Дата подтверждается именами дампов и наличием событий до 7 ноября. Точное общее время транзакционно согласованного среза двух баз требует подтверждения.

Исходный SQL прочитан как данные. Подготовлены 12 CSV с псевдонимами пользователей бота и аккаунтов панели. В публичный комплект входят расчёты и агрегаты. Для запуска нужен разрешённый локальный экспорт.

## Воронка

Единица расчёта — пользователь с первой сохранившейся записью пробной подписки. Полное окно наблюдения составляет семь суток. Расчётная граница — 7 ноября 2026 года, 00:00 UTC. Из знаменателя исключаются пользователи с неполным окном и найденной успешной оплатой до старта.

Связь подписки с панелью проводится по аккаунту пробной записи. Отдельная проверка аудитории помощи учитывает другие связанные аккаунты. Оплата определяется как положительная нетестовая транзакция со статусом COMPLETED на снимке. Время создания и последнего обновления проверяются как альтернативные приближения к моменту оплаты.

Панель хранит некоторые даты без часового пояса. SQL проверяет сценарии UTC и UTC+3. Результат по активации чувствителен к этому допущению. Полная история статусов платежа и исходных пробных выдач в текущих записях может отсутствовать.

## Приложения

Источники — регистрация устройства и запрос конфигурации. Для устройств используются поля user, panel_user, platform, app, created_at. Для запросов — user, panel_user, app, request_at.

Уникальные пользователи подсчитываются отдельно внутри группы. Пользователь может пользоваться несколькими клиентами. Объединение двух клиентов считается с устранением повторов.

Окно последних календарных дат — 8 октября по доступную часть 7 ноября включительно. Верхняя граница фильтра 8 ноября исключается. Внутри окна у разных пользователей различная длительность наблюдения.

Названия классифицированы по явным признакам user-agent. Повторная проверка расширенного списка названий не изменила классификацию. Неизвестные значения сохранены как Other. FlClash и FlClashX требуют сверки соответствия, Clash Mi и Clash Meta учитываются отдельно. События на уровне аккаунта панели не позволяют достоверно приписать успешное подключение конкретному приложению.

## Ограничения и статус

Выгрузка содержит исторические записи, а интерфейс осмотрен 7 ноября. Их соответствие на каждую историческую дату ещё не установлено. Тестовая выдача и действия при осмотре относятся к отдельному тестовому аккаунту и исключаются из будущего пилота. История одного аккаунта не доказывает общее расписание уведомлений.

Предложения по изменению процесса подготовлены для обсуждения с владельцем. Приёмка, запуск и измерение эффекта планируются после согласования.
